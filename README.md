A deterministic mean-reversion trading bot for hourly Solana bars: it buys oversold dips below the 20-bar Bollinger lower band (plus quick scalps on sharp 6-bar drops), sells the reversion to the mean, and staggers entries to beat buy-and-hold without ever chasing a rally.

## Run it

```sh
node main.ts
```
